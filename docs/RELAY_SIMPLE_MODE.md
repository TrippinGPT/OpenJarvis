# Relay Simple Mode

Relay Simple Mode exists to reduce cockpit overload.

It keeps the operator focused on four things:

- one main task input
- one recommended agent
- one short explanation of why that agent fits
- one clear next action

## What Simple Mode shows

- the Relay companion header and core HUD
- a plain-language task input area
- the current recommended specialist
- the current next suggested move
- a compact agent quick guide
- a clear `Show advanced` path

## What Simple Mode hides by default

- detailed structured memory internals
- routing detail blocks
- usage review internals
- placeholder voice controls
- extra status and telemetry clutter

Those remain available through Advanced mode. No capability was removed.

## Why it exists

Relay had enough useful surfaces to become harder to scan than to use. Simple Mode makes the first action obvious without deleting the deeper cockpit tools.
